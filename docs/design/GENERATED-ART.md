# Original environment artwork

The four new environment backdrops were generated with the built-in image-generation tool as one 1536×1024 four-panel atlas, then cropped and encoded as WebP.

- wonderwood.webp: Size — enchanted woodland clearing.
- drop-shop.webp: Count — warm toy workshop.
- stargazer.webp: Guess — midnight observatory.
- word-garden.webp: Estimate — lantern-lit library greenhouse.

Prompt: Create four equal rectangular panels in a 2×2 grid; original whimsical pixel-art indie-game backdrops; crisp square pixels; no typography, logos, or interface. Enchanted mint woodland with mushrooms and creek; amber toy workshop with blocks, conveyor and brass drop chute; lavender midnight observatory with telescope and planets; rose library greenhouse with books, vines, lanterns and blank stone tiles. Same palette and pixel size, detailed edges, calm centers for controls.

Existing harbor and reef environments remain in use. CSS particles and light overlays animate the scenes; reduced-motion preferences disable ambient animation.
