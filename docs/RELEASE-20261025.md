# Gameplay and service repair, 25 October 2026

This is an incremental release, not completion of the requested eleven-game overhaul.

## Changes

- New Fish rounds use versioned `catch-v1`: tap a correct answer fish as it crosses a gold zone. Correct catches add 100 points (maximum 1,000); incorrect fish in the zone subtract 50 (minimum zero); timing misses add zero. A 650 ms server interval and one cast per fish/pass prevent repeated scoring. Server time determines the 3.6 second swim cycle; a 150 ms delivery grace follows the visible window. Client timestamps and score fields are never accepted. Existing published Fish rounds retain their original selection rules. Points and catches survive reconnection/restart. The whole lane is a stable touch target.
- Claw prizes can be tapped to aim, avoiding required hold-arrow positioning. Sling's launch button is always visible. Drop offers two direct True/False actions and no longer forces scrolling at launch. Guess no longer opens the phone keyboard on mount over its own keyboard; spellcheck is disabled.
- Sign-in feature discovery retries transient service startup errors with a bounded six-attempt budget and provides an in-page retry. Credential POSTs are never automatically retried. Before credentials are submitted, a side-effect-free readiness request checks the service.
- PostgreSQL cleanup now uses JSONB predicates/values instead of text LIKE and text assignment. Cleanup failures no longer prevent the generation worker from running and have a separate log event.
