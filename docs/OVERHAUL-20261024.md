Removed the legacy rule pinning every full-width game button to the same viewport position. This still requires browser verification at every requested breakpoint.

Unknown IDs, overrides, unrelated topics, duplicate IDs, unsupported difficulty and arithmetic worksheets are rejected. Requests without sufficient verified coverage fail before a provider call and return credits through the existing worker failure path.
- Updated fishing instructions to match selection/reeling. Existing scoring and authoritative server input rules are unchanged.

## Content limitations

The eight-fact starter bank covers parts of science, space, chemistry and UN history. It does **not** provide broad category coverage or enough facts for arbitrary twenty-question requests. Expand it editorially before calling generation production-complete. Other modes still require creator review and do not have independent factual verification. No paid generation evaluation batch was run.

Primary evidence checked: Royal Society of Chemistry gold element page; NASA Earth facts and planet sizes; UN About Us. Source URLs are retained with each fact. Approximate values specify rounding or measurement convention. Historical UN membership uses 1945 rather than an undated current count.
